# Contributing Guidelines

Thank you for contributing to our open source project. Please read this guide before submitting a Pull Request.

## 1. Development Workflow

1. Fork the repository to your personal account.
2. Create a feature branch (`git checkout -b feat/new-feature`).
3. Commit your changes following Conventional Commits.

## 2. Testing and Validation

Run the automated test suite using:

```bash
npm test
```

## 3. Issue Reporting Guidelines

| Category | Description | Priority |
| :--- | :--- | :---: |
| Bug Report | Step-by-step bug reproduction | High |
| Feature Request | User scenario description | Medium |
