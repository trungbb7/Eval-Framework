# Payment Feature V2

The new payment system allows users to checkout relatively fast with an extremely friendly UI.

### 1. Description
The checkout UI will be loaded by the application when clicking the buy button.
The system will load data very quickly and process many transactions concurrently.

### 2. Requirements
- The checkout button should be clickable.
- Should handle high traffic.
- Report an error if payment fails.

### 3. Audience
For all users in the system.
