# C++ Code Review Plugin

This plugin provides automated C++ code review tools, safety auditing agents, and modern C++ best practices guidelines for Claude Code.

## Features Included
- **Slash Command**: `/review-cpp` - Quick standard review of C++ code changes.
- **Sub-Agent**: `cpp-auditor` - Deep security and memory audit sub-agent.
- **Skill**: `cpp-best-practices` - Automatic guidelines for modern C++20 standard compliance.

## Installation
When installed via the marketplace:
```bash
claude plugin install cpp-code-review@demo-claude-marketplace
```
